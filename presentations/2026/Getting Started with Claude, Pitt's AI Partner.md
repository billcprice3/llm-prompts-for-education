# Getting Started with Claude, Pitt's AI Partner
### TiLT Forum, September 11, 2026

---

## Intro

The University of Pittsburgh has a partnership with Anthropic that gives all faculty, staff, and students premium access to Claude, an AI assistant similar in purpose to ChatGPT, Gemini, or Copilot. 

If you already use one of those tools, most of what you know transfers directly. The main difference is data security. Under Pitt's AI classification system, Claude is **approved** for "Public," "Private," and "Restricted" data. This includes **FERPA-covered student information** (names, emails, grades, etc.). Full details: [University AI Approved Tools List and Data Classifications](https://services.pitt.edu/TDClient/33/Portal/KB/Article/2792/University-AI-Approved-Tools-List-and-Data-Classifications)

## Getting Started

Claude can be accessed four main ways:

1. **Website**: [claude.ai](https://claude.ai), in any browser
2. **Desktop app**: native applications for Windows and Mac
3. **Mobile app**: iOS and Android
4. **Plugins/extensions**: add-ins for programs like Microsoft Word, Excel, PowerPoint, and Outlook, plus a Chrome browser extension

All four use the same Pitt-affiliated account, and your conversations and data should sync across them.

**Pitt Digital resources:**
- [Generative AI @ Pitt](https://www.digital.pitt.edu/ai)
- [Claude for Education service page](https://services.pitt.edu/TDClient/33/Portal/Requests/Service/397/Claude-for-Education)

### Logging in

1. Go to [claude.ai](https://claude.ai)
2. Enter your full Pitt email address (`@pitt.edu`)
3. Click **Continue with SSO**
4. You'll be redirected to a Microsoft login page. Enter your Pitt email address again.
5. You'll then land on the Pitt Passport login page. Enter your credentials there and log in to finish.

## Let's Try This Together: Canvas Roster to Spreadsheet

This activity is designed to reinforce a few ideas:

- It's fine to put student information into Claude through your Pitt account;
- Claude can generate real files (not just chat text);
- Claude can help with tedious formatting/administrative tasks.

Follow along and try this with your own data.

1. Open a new Claude chat.
2. In another tab, open the Canvas page for a course you're teaching and go to the **People** tab.
3. In the Claude chat, type:

   > Please turn this pasted information from Canvas into a spreadsheet file.

   Then paste all the student info from the Canvas People tab underneath that instruction, and send the message.
4. Claude should return an XLSX file containing the student data. Download it, open it, and check that it looks correct.
5. Now give Claude this task:

   > I want to add an email address column. Just add @pitt.edu to the login IDs.

6. Claude should return a revised XLSX file containing the new column for email addresses. Download it, open it, and check that it looks correct.

## More to Explore

Beyond the chat window, Anthropic also offers extensions that put Claude directly inside other software you may already use; Word, Excel, PowerPoint, Outlook, and Chrome among them. You can browse these plugins and extensions at [claude.ai/download](https://claude.ai/download).

However, note that this kind of integration with other software is a more "prototype-level" experience. It's newer, rougher, and not as refined as the core chat experience.
